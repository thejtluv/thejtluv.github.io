3 buttons

Left button ☰
- single tap repeatedly to cycle through the 4 Menus
- hold when in A/C or heat menus to turn off (displays OF)

Middle button - adjust the current menu setting down: ▼

Right button - adjust the current menu setting up: ▲

Menus

In order of icon location on the display, left to right:

  • 🌡️ Vent temp - live current vent temp to help determine desired A/C or heat set points (no adjustment here)
  • ❄️ Set point for A/C - vent temp at which A/C will come on (below) and go off (above)
    • Use up/down buttons to turn on and adjust
    • Hold left = button to turn off (displays OF)
  • 🔥 Set point for heat
    • Use up/down buttons to turn on and adjust
    • Hold left = button to turn off (displays OF)
  • 🌀 Fan speed set point (0-10)
    • Use up/down buttons to adjust
    • This is the speed the fan will run while on this menu, or any other time it's tripped by set points
    • Leaving set to this menu, the fan will run forever at this speed, including zero
Notes

Adjust the A/C and/or heat temp set points to dictate when the fan comes on and goes off

Example where you want to heat up the room (works same in reverse for A/C):

  • Room is currently 60 degrees
  • 🌡️ vent temp showing 65 degrees
  • 🔥 vent set point for heat showing 85 degrees (and is therefore on)
  • Ecobee gets set to 69 degrees by schedule (was 60 overnight)
  • Vent starts to heat up, and when it reaches 85 degrees starts the fan (still 60 in the room)
    • 🌡️ Vent temp may show way higher than desired Ecobee temp of 69
  • When the room hits 69 degrees according to Ecobee, heat turns off
  • Fan keeps blowing residual heat from the vents until 🌡️ Vent temp slowly cools to less than set point of 85
  • Rinse, repeat

In that scenario, the lower you set it (say 85 down to 80) the sooner it will come on, and the longer it will take to go off.
